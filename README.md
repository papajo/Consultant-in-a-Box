# Consultant-in-a-Box

**Multi-agent RFP triage and an evidence-backed decision engine, powered by Gemini.**

Small consultancies and agencies lose hours reading long RFP documents and still make go / no-go decisions on gut feel. Consultant-in-a-Box parses bid documents in the browser and has specialist AI agents triage each opportunity — surfacing the requirements, risks, and fit evidence — so a human can decide in minutes, with citations, not vibes.
